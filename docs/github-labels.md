# Empfohlene GitHub-Labels

| Label | Zweck |
| --- | --- |
| `good first issue` | Klar abgegrenzter Einstieg ohne Datenmigrationsrisiko. |
| `help wanted` | Beitrag aus der Community erwünscht. |
| `documentation` | README, Architektur, Betriebs- oder Nutzerhilfe. |
| `accessibility` | Tastatur, Screenreader, Kontrast oder Zoom. |
| `security` | Sicherheitsrelevant; keine vertraulichen Details in öffentlichen Issues. |
| `testing` | Unit-, Integrations-, E2E- oder Regressionstests. |
| `backup` | Backup, Restore oder Sicherungsstatus. |
| `migration` | Datenformate, Validierung oder Rückwärtskompatibilität. |
| `teacher feedback` | Rückmeldung aus der Unterrichtspraxis. |
| `breaking change` | Erfordert Migration, klare Release-Notes und Review. |

Labels werden nur dokumentiert; diese Änderung erstellt keine GitHub-Issues und verändert keine Repository-Einstellungen.
